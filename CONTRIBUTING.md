# Contributing to NewTerminal

Thank you for your interest in contributing to NewTerminal! We welcome contributions from the community.

## How to Contribute

### Reporting Issues
- Use the [GitHub Issues](https://github.com/muhibalkarim/NewTerminal/issues) page
- Search existing issues before creating a new one
- Provide clear steps to reproduce the problem
- Include your OS, Python version, and error messages

### Suggesting Features
- Open an issue with the "enhancement" label
- Describe the feature and its use case
- Explain why it would benefit NewTerminal users

### Code Contributions

#### Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/NewTerminal.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`

#### Making Changes
- Test your changes on multiple platforms (Linux, macOS, Windows)
- Follow existing code style and patterns
- Add comments for complex logic
- Update documentation if needed

#### Submitting Changes
1. Commit your changes: `git commit -m "Add: brief description"`
2. Push to your fork: `git push origin feature/your-feature-name`
3. Open a Pull Request with:
   - Clear description of changes
   - Reference to related issues
   - Testing details

## Development Guidelines

### Code Style
- **Shell scripts**: Follow POSIX standards where possible
- **PowerShell**: Use approved verbs and proper error handling
- **Documentation**: Use clear, concise language

### Testing
- Test installers on clean systems
- Verify cross-platform compatibility
- Test with different RAM configurations
- Ensure models download and work correctly

### Commit Messages
- Use present tense ("Add feature" not "Added feature")
- Keep first line under 50 characters
- Reference issues: "Fix #123: resolve installation error"

## Areas for Contribution

- **Platform Support**: Improve installers for specific OS versions
- **Error Handling**: Better error messages and recovery
- **Documentation**: Examples, troubleshooting guides
- **Testing**: Automated tests for installers
- **Features**: New shell integrations, model options

## Questions?

Feel free to open an issue for questions about contributing. We're here to help!

## Code of Conduct

Be respectful, inclusive, and constructive in all interactions. We want NewTerminal to be welcoming for everyone.
